
# Food Donation Management System

## Project Description

The Food Donation Management System is a Python-based
application designed to reduce food wastage and help
people in need.

The system connects food donors with volunteers who
collect and distribute donated food.

## Objectives

1. Reduce food wastage.
2. Connect donors with volunteers.
3. Manage food donation records.
4. Track food collection and delivery.
5. Support food distribution.

## Technologies Used

- Python
- JSON
- Object-Oriented Programming
- File Handling
- Exception Handling

## Project Modules

1. User Registration
2. Food Donation Creation
3. View Available Donations
4. Claim Donations
5. Update Donation Status
6. View All Donations

## Project Structure

Food_Donation_System/

## How to Run

1. Install Python.
2. Open the project in VS Code.
3. Open the terminal.
4. Run the following command:

   python main.py

## Donation Status

- Available

## Conclusion

This project provides a simple solution for
managing food donations and reducing food wastage.

It helps donors and volunteers work together
to distribute food to people in need.
